🌦️ RakeshKaAakash – Weather Intelligence Dashboard

📖 Project Description

RakeshKaAakash is a Weather Intelligence Dashboard built using TypeScript, Vite, and modern frontend tooling. It leverages SDD (Specification-Driven Development) principles to ensure clarity in design and implementation.

The app provides:

Real-time weather insights with a clean UI.

Modular architecture (src, tests, specs) for scalability.

Integration-ready setup for future AI-driven analytics.

Configurations managed via Vite and TypeScript for fast builds and type safety.


🔧 Tech Stack
Frontend: TypeScript, Vite, React HTML, CSS

Automation/Config: PowerShell, Shell scripts

Testing: Unit tests under /tests

Specifications: Located in /specs/003-weather-intelligence-web-app

🚀 Getting Started
1. Clone the Repository
bash
git clone https://github.com/RackeshKamble/RakeshKaAakash.git

cd RakeshKaAakash

2. Install Dependencies

npm install

3. Run the Development Server

npm run dev

4. Build for Production

npm run build

5. Run Tests

npm test



📂 Project Structure
src/ → Core application code

tests/ → Unit and integration tests

specs/003-weather-intelligence-web-app/ → Specification-driven design docs

index.html → Entry point

vite.config.ts → Vite configuration

package.json → Dependencies and scripts
